# Requirement close vectors

`vectors.json` is copied byte for byte from bob-cli's
`tests/fixtures/req_close/vectors.json`. bob-cli owns the fixture and its
contract; update it there first, then copy it here and verify with `cmp`.
The surrounding response fixtures in `Tests/Fixtures/capture-req-close-*.json`
are generated by `Scripts/generate-req-close-fixtures.sh` from a current Bob
binary. The default-Met fixture also verifies that the owner closes while all
requirement checkbox bytes remain unchanged.

`run` is the constant `◇` fallback at every depth. `copy.glyph` is the semantic
`requirement` token; the app draws its own state mark. The response fixtures also
exercise additive `req: {depth, state}` on preview lines, with the legacy fixture
omitting those annotations.
