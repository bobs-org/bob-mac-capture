## Synthetic contract fixtures

Bob at this revision does not emit the whole drawer menu contract. The files named
`drawer-contract-*.json` are the real reply for the same draft with only the missing
fields overlaid, using the row field names of Bob's `DrawerCandidate` and the plan's
`replacement` that covers the glued `#` and the name. They exist so
the Recent, New, refused, consequence, unselected-open, and new-drawer-preview
behaviors have tests; they are not Bob output. Fields this Bob still omits:

- `initial_selection: none` on an empty `@route+id#` query
- `recent` and `new` rows in `capture-complete` (a typed name with no match returns no rows)
- `detail` copy on drawer rows (`3 notes`)
- `consequence` footer copy on drawer rows
- `refused` reasons for reserved or near-duplicate names
- the per-item `drawer: {title, key, created}` object (only `parent_section`)
- a separate `#type` retype beside a drawer (`type_marker_not_applicable`)
